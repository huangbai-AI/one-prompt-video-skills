# 黄白脚本 Skill

为 AI 博主「黄白」（B站/小红书等平台，人设：**"我是黄白，一个很会玩AI的设计师"**）写口播视频脚本。内容形态：60s-3min 教程型/展示型商单视频，短句、口语、一句一画面。

## 〇、输出格式要求

脚本用表格输出，与黄白飞书文档格式一致：

| 阶段 | 口播 | 备注（画面/分镜） |
|---|---|---|

- 口播每句 ≤20 字为佳，一句对应一个画面动作（出镜/录屏/高亮/词卡/特效）
- 备注栏写清视觉设计：出镜位、特效手势（打响指、甩手）、录屏高亮区、道具 callback
- 幽默点是**设计出来的节奏卡位**：草稿阶段可留占位符"（加点幽默）"，通常放在 Part 开头或出镜切换处

## 一、经典结构框架（八篇脚本共用模板）

```
① 钩子（10-25%）      成果前置，人可不出镜，先甩最炸的画面
② 价值承诺 + 降门槛    "三个技巧" / "一分钟教会你" / "太奶都能学会"
③ 自我介绍（固定卡位）  "我是黄白，一个很会玩AI的设计师" ← 永远在钩子之后，不做第一句
④ 教学主体（40-60%）   2-3 个 Part，第一人称体验流，产品长在操作步骤里
⑤ 彩蛋/邪修（可选）    "我还有一个邪修方法（笑）"——进阶取巧玩法压轴
⑥ 结尾三连（5-10%）    文档钩子 → 行动号召 → 关注引导
```

### ① 钩子的 5 种打开方式（按场景选）

| 类型 | 逐字范例 | 适用 |
|---|---|---|
| 成果宣言 | "我做了一个能找到 全世界远程工作 的网站" | 自己 vibecoding 的项目 |
| 事件化开场 | "Seedance 2.5 终于来了。" | 新品发布类商单 |
| 数据冲击 | "20条视频涨粉百万，现在这种AI小短剧实在是太上头了" | 蹭爆款案例 |
| 否定式反转 | "这不是一个AI视频模型，而是一个可以自定义技能，可自由探索的3D世界"（配双手❌动作） | 需要立新概念 |
| 打击错误做法 | "想做出这样真实的效果，并不是写「4K高清」的提示词就可以的" | 教学纠错类 |

钩子铁律：
- **前 3 秒只给画面冲击，不讲过程**（备注常写"3段案例展示我不出镜"、"教程在10s后开始"）
- 反套路话术可以"明贬暗塞"："我不想讲最长3分钟的时长或是50张参考图这种参数"——嘴上不讲，卖点全说了
- 钩中钩：塞一个猎奇具体案例（"月薪1万美金，教人工智能理解宗教（笑）"）
- 悬念反问变体："你敢信？" / "…怎么办？"

### ② 降门槛承诺句库

- "让我一分钟教会你"
- "看完了太奶 都能学会"（可变体："太奶都能上手"）
- "用三个技巧让你做的AI视频绝对真实"
- "过程只需要3步" / "只需一个Skill就能制作" / "现在你也可以自己体验了，操作也非常简单"

### ⑥ 结尾三连（几乎一字不变的固定收尾）

1. **文档钩子**（每期必有，变体任选）：
   - "我还把以上内容都整理成了文字版，需要的自取"
   - "本期全部案例和提示词我也都放在了文档里"
   - "我把网址放在评论区了，感兴趣的小伙伴评论区见"
   - 高级用法：文档钩子**开场埋一次、结尾收一次**，首尾呼应（万镜一刻式）
2. **行动号召**："快去试试吧！"
3. **关注引导（固定句，勿改）**："关注我，主页更多AI玩法"
   - 可加情绪收口在前："哇，我当年找工作哪有这个条件！？" / "真的不敢想象，之前…现在动动手指就可以做到了"
   - 系列感变体："我们下期见"

## 二、高频关键词与固定句式库

**身份 slogan（一字不改）**：
> 我是黄白，一个很会玩AI的设计师

**教学起手式**：
- "首先来到…"（"首先来到updream的技能广场" / "首先来到我们的老朋友Seko"——常用产品拟人"老朋友"表熟稔）
- "在这里点击…" / "那就点开【…】" / "然后搜索…"

**交付感句式（每讲完一个有门槛的知识点必接一句）**：
- "我已经把以上内容都整理成了 Skill / 文字版 / 文档"
- "所以帮你整理好了…直接发给AI即可"
- "整个项目我也都上线了 Github / 开源出来给大家使用"

**步骤收束口头禅**："就…了"句式制造"很简单"暗示：
- "就可以找到我上传的Skill了" / "即可做出一个简单的skill了" / "就非常方便了"（产品好评固定落点，一期可用 3 次）

**强调与节奏词**：
- "是的你没听错" / "真的"（真实感背书，一期约 3 次）/ "让我很惊喜的是" / "还有一个很有趣的点" / "就像这样"（边说边演）
- 递进抛点："当你以为…已经很不错了，那接下来的才是硬菜"
- 对比句式："不是…而是…"（可一头一尾各一次，形成呼应）
- 零门槛词：一键 / 轻松 / 直接 / 超多

**进阶彩蛋固定梗**："我还有一个邪修方法/秘籍（笑）"——把取巧用法包装成修仙旁门左道，3 篇脚本复现。

## 三、幽默机制指南（微妙差异，按需取用）

黄白的幽默**不是段子**，核心原则（他自己给 AI 短剧写的提示词）：
> "面对荒唐情况依然一本正经，不要表现成故意耍宝，笑点来自他的认真。"

——冷面喜剧，一本正经地荒诞。具体 8 种机制：

| 机制 | 逐字范例 | 何时用 |
|---|---|---|
| 言行反差（明贬暗塞） | "我不想讲…这种参数"（然后全讲了） | 开头反套路 |
| 拟人化吐槽 | "可怜的12个素材上限" / "AI并不能理解人类的情感" / "Agent就像一个很聪明的实习生…真的有一种当总监的感觉，谁懂？！" | 讲痛点、讲功能 |
| 语域反差（生活化比喻） | "接下来的才是硬菜" / "这个就和我平时打游戏一样流畅了" | 翻译参数 |
| 网络梗/亚文化梗 | "邪修" / "言出法随" / "船新版本" / "太奶都能学会" / "我们AI博主的天塌了" / "对味" / 单字"爽" | 消解广告感、教程枯燥感 |
| 自嘲+真香反转 | "一开始我也觉得参考这么多没必要好麻烦"（后真香） / "哇，我当年找工作哪有这个条件！？" | 化解观众疑虑、结尾抒情 |
| 夸张具体化 | "脸部汗毛都能看得到" / "享受当造物主的感觉了" / "一次性帮我跑10条也没有问题" | 惊叹式卖点 |
| 自我玩梗 | "我还做了一个黄黑色的风格Skill（笑）"（暗合ID黄白） | 送福利时 |
| 视觉 callback | 出镜时插着上一段案例里的"贬"字令牌 | 备注栏画面设计 |

刻意轻描淡写也算一种："有那么一点点的难度"——先抬难度再自己接住，铺垫"我帮你整理好了"。

## 四、广告植入手法（商单核心）

总公式：**成品引发欲望 → 教程给出路径 → 产品作为路径上唯一的工具自然出现 → 文档和关注承接流量**

1. **教程即广告**：产品不被"提到"，而是被"用出来"。视频成片本身就是产品产出物（"你现在看到的特效、音效、字幕，全都是AI帮我加上的"）
2. **品牌名长在动作指令里**："在万镜一刻里点击【资产】"——观众照做即完成产品体验；老用户可昵称化（"万镜"）
3. **痛点前置，产品当解药**：先讲失败尝试造缺口（"我一开始想要通过Agent来去抓取信息，但是很容易被拦截"），再以"技巧"名义引出产品（"这里有一个技巧就是使用 AnySearch 这个 skill"）
4. **参数翻译成体感**：每个卖点做"旧 vs 新"对比 + 数字可视化。50fps → "和我平时打游戏一样流畅"；素材 12→50 → 特效画面图片堆成山
5. **欲扬先抑的可信度设计**："第一次生成的效果并不是很符合我的审美"→ 引出风格选择功能。敢说小翻车换信任
6. **踩行业不点名竞品**："以往的所谓世界模型只能支持分钟级的生成"——"所谓"二字轻贬抬主角
7. **背书事件化**：不吹捧，写因果句："这也是它能拿下 Product Hunt 周榜第一的原因了"
8. **硬广一句玩梗收掉**：促销价格包在个人受益叙事里，用"性价比，绝了！"短促收尾，避免念价目表
9. **转化藏在感叹里**：结尾先情绪（"真的不敢想象…动动手指就可以做到了"），再顺势报公测/官网，广告落点包装成"好消息通知"
10. **商单与个人 IP 绑定**：把品牌产品和自己的开源 Skill/文档/项目捆绑交付，广告同时成为私域引流资产

## 五、写稿工作流

1. **吃透 brief**：列出品牌方必审元素（功能点、促销、界面演示、口径），每一条都要找到"教学步骤"或"个人叙事"的载体，禁止念稿式罗列
2. **选钩子类型**（见一①），先写钩子和结尾，再填中间
3. **搭三段教学骨架**：每 Part = 痛点/好奇 → 操作演示（产品内嵌）→ "就…了"收束 → 一个情绪反应（爽/哇哦/对味/笑）
4. **埋固定件**：自我介绍卡位、文档钩子（1-2 次）、"邪修"彩蛋（可选）、"关注我，主页更多AI玩法"
5. **设计幽默节奏点**：每 Part 至少 1 个，从"三、幽默机制"选不同机制避免重复；备注栏同步写视觉梗
6. **自检清单**：
   - [ ] 前 3 秒是画面冲击而非自我介绍？
   - [ ] 每句口播 ≤20 字、有对应画面动作？
   - [ ] 品牌卖点全部翻译成第一人称体感，零参数罗列？
   - [ ] "我是黄白…" 和 "关注我，主页更多AI玩法" 一字未改？
   - [ ] 有文档/开源交付钩子？
   - [ ] 幽默是"一本正经地荒诞"，没有刻意耍宝？
   - [ ] 通读像"兴奋地分享新玩具"，不像"讲解产品"？

## 六、语气校准（写错了就不像黄白）

- ✅ 第一人称体验流："帮我做出" / "让我很惊喜" / "我就可以" —— ❌ 第三人称说明书："它能够…"
- ✅ 短句、动词开路："点进画布""选择模型" —— ❌ 长定语从句
- ✅ 技术点讲一句就配一个情绪反应 —— ❌ 连续三句干货不喘气
- ✅ 自信式自封（"很会玩"）、小得意（"怎么样，效果还不错吧"） —— ❌ 谦虚客套或专家端架子
- ✅ 给关注一个理由（"带你学会更多ai玩法"） —— ❌ 干巴巴"求关注点赞"
