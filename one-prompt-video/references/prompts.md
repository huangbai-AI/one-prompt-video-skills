# 提示词

把【】里的内容换成你的。

## 写稿（配合写稿 skill）

```
请用「写稿 skill」帮我写一条 2 分钟左右的口播视频脚本。
主题：【这期讲什么】
观众：【给谁看】
必须出现的事实：【名字、数字、产品】
输出三列分镜表：阶段｜口播｜画面。
画面列标明每句用口播画面还是 B-roll；B-roll 再写清是截图、本人素材还是说明动画。
口播按每段不超过 15 秒拆开，并标出每段起止。
```

## 口播画面（即梦 CLI · Seedance 2.5）

```
用即梦 CLI 生成口播画面：
参考图：【一张本人正脸照】
参考音频：【一段 8 秒左右的本人声音】
按分镜表逐段生成，每段不超过 15 秒，模型 Seedance 2.5，画幅 16:9。
每段提示词：用参考音频里相同的声音、音色和语气，面对镜头只说这一段台词，一字不改；口型逐字同步；正脸、固定机位；画面里不要字幕和文字。
生成后把每段声音转成文字，和台词逐字核对，把不一致的段落列给我。
```

## B-roll 截图

```
按分镜表里标为「截图」的每一行，用浏览器打开对应页面：【页面地址或要找的内容】
截取和这句台词相关的区域，保存为 16:9 图片，文件名用分镜行号。
页面里出现平台标识、账号信息或隐私内容的地方，统一打码。
```

## 说明动画（配合代码动画 skill）

```
用「代码动画 skill」为分镜表里标为「说明动画」的每一行，做一段 16:9 动画。
风格：现代、克制；深色底，只用一个强调色。
每个动画在对应台词出现时入场，时长跟这句台词一致。
先渲染 10 秒草稿给我确认节奏，再出全部。
```

## 合成与检查（HyperFrames）

```
用 HyperFrames 把口播画面和全部 B-roll 按分镜表合成一条 16:9 成片。
口播先粗剪：只在停顿处下刀，每句话讲完留 0.5–1 秒气口；口播画面不缩放、不调色。
每个 B-roll 卡在触发它的那句台词上；B-roll 播放时，口播缩成右下角小窗。
字幕按台词逐句生成；配一段原创背景音乐，人声出现时自动压低。
分段渲染，改哪段只重渲哪段；渲染后每 2 秒抽一帧检查：文字出框、画面穿帮、卡帧、声音与台词是否一致、有无黑帧。
有问题就修改后重新渲染，直到全部通过。
```
